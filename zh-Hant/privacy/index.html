隱私權政策

生效日期 2026 年 11 月 19 日 · 營運者 Davy Kim (ipe Studio)

摘要 Mongsil 不收集個人資料，沒有專用伺服器、ipe 帳號、廣告或分析工具。

1. 收集的資料

Mongsil（以下稱「本程式」）是由獨立開發者 Davy Kim（ipe Studio）營運的手機遊戲。本程式不設 ipe 帳號或註冊，不收集姓名、電子郵件、聯絡資料或位置等個人資料。裝置的隨機識別碼只用於區分各裝置的遊戲幣紀錄。啟用 iCloud 時，識別碼可能隨進度同步到你自己的 iCloud，且不會傳送給 ipe。照顧紀錄、設定及圖鑑儲存在裝置上，只在啟用 iCloud 時同步。ipe 不會收到這些資料。刪除本程式也會刪除裝置上的資料。

本程式未包含廣告、分析或追蹤 SDK。

2. 裝置儲存與 iCloud

目前的 iOS 版本會把進度存在裝置上。若在 iPhone 啟用 iCloud，進度可透過 Apple 的 iCloud 在登入同一 Apple 帳號的裝置間同步。ipe 沒有專用伺服器，也不會收到這些資料。

本程式在其他平台推出時，我們會更新本政策。

3. 網站

mongsil.ipe.rest 沒有收集瀏覽統計的分析工具。網站由 GitHub Pages 託管，IP 位址等瀏覽紀錄可能保存在 GitHub 伺服器日誌中。我們不收集或使用這些日誌，相關紀錄適用 GitHub 的政策。

4. 付款

付費道具只能透過 Apple 的 App Store 內購買取得。Apple 處理卡號、付款方式等資訊，Mongsil 和 ipe 不會收到或保留這些資訊。購買驗證和恢復以 Apple 商店紀錄為準。

5. 第三方

本程式不收集個人資料，因此沒有可供分享或出售給第三方的個人資料。本程式由 Apple App Store 提供，下載和付款相關資訊由 Apple 依其隱私權政策處理。

排行榜（Apple Game Center）為選用功能。使用時，分數和 Game Center 暱稱會傳送給 Apple，並由 Apple 依其隱私權政策處理。這些資料不會傳到 ipe 的伺服器，ipe 也不會收到。

6. 詢問及你的權利

如需查閱、更正、刪除或停止處理個人資料，或有任何問題，請聯絡 ipe.haven@gmail.com。本程式沒有保存個人資料，所以可能沒有可供處理的資料。

7. 兒童

本程式不以未滿 14 歲（或未達所在地最低年齡）的兒童為對象，也不收集任何使用者的個人資料。

10. 變更

若日後新增伺服器、帳號、廣告或分析功能，並因此改變收集資料的範圍，我們會先更新本政策和生效日期。
