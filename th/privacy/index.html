นโยบายความเป็นส่วนตัว

มีผลตั้งแต่ 19 พฤศจิกายน 2026 · ดำเนินการโดย Davy Kim (ipe Studio)

สรุป Mongsil ไม่เก็บข้อมูลส่วนบุคคล และไม่มีเซิร์ฟเวอร์ของเกม บัญชี โฆษณา หรือเครื่องมือวิเคราะห์

1. ข้อมูลที่เก็บรวบรวม

Mongsil (“แอป”) เป็นเกมมือถือที่ดำเนินการโดยผู้พัฒนาอิสระ Davy Kim (ipe Studio) แอปไม่ต้องใช้บัญชีหรือเข้าสู่ระบบ และไม่เก็บชื่อ อีเมล ข้อมูลติดต่อ ตำแหน่ง หรือข้อมูลส่วนบุคคลอื่น แอปสร้างรหัสสุ่มสำหรับแต่ละอุปกรณ์เพื่อแยกบันทึกเหรียญเท่านั้น เมื่อเปิดใช้ iCloud รหัสนี้อาจซิงค์ไปกับความคืบหน้าใน iCloud ของคุณเอง โดยไม่ส่งให้ ipe บันทึกการดูแล การตั้งค่า และคอลเลกชันจะอยู่ในอุปกรณ์และซิงค์เฉพาะเมื่อเปิดใช้ iCloud เท่านั้น ipe ไม่ได้รับข้อมูลเหล่านี้ เมื่อลบแอป ข้อมูลของแอปในอุปกรณ์จะถูกลบด้วย

แอปไม่มีโฆษณาหรือ SDK สำหรับการวิเคราะห์หรือการติดตาม

2. การเก็บข้อมูลในอุปกรณ์และ iCloud

ในเวอร์ชัน iOS ปัจจุบัน ความคืบหน้าจะบันทึกในอุปกรณ์ หากเปิดใช้ iCloud บน iPhone ความคืบหน้าจะซิงค์ระหว่างอุปกรณ์ที่ใช้บัญชี Apple เดียวกันผ่าน iCloud ของ Apple ipe ไม่มีเซิร์ฟเวอร์ของเกมและไม่ได้รับข้อมูลนี้

เราจะปรับปรุงนโยบายนี้หากเปิดตัวแอปบนแพลตฟอร์มอื่น

3. เว็บไซต์

mongsil.ipe.rest ไม่มีเครื่องมือวิเคราะห์ที่เก็บสถิติการเข้าชม เว็บไซต์ใช้บริการ GitHub Pages หมายเลข IP และบันทึกการเข้าถึงอื่นอาจอยู่ในบันทึกเซิร์ฟเวอร์ของ GitHub เราไม่เก็บหรือใช้บันทึกดังกล่าว และใช้นโยบายของ GitHub กับบันทึกเหล่านั้น

4. การชำระเงิน

ไอเทมแบบชำระเงินจำหน่ายผ่านระบบซื้อภายในแอปของ Apple บน App Store เท่านั้น Apple จัดการข้อมูลการชำระเงิน เช่น หมายเลขบัตรและวิธีชำระเงิน Mongsil และ ipe ไม่ได้รับหรือเก็บข้อมูลนี้ การตรวจสอบและกู้คืนการซื้อใช้ข้อมูลของร้านค้า Apple

5. บุคคลที่สาม

แอปไม่เก็บข้อมูลส่วนบุคคล จึงไม่มีข้อมูลให้เปิดเผยหรือขายแก่บุคคลที่สาม แอปเผยแพร่ผ่าน Apple App Store โดย Apple จัดการข้อมูลการดาวน์โหลดและชำระเงินตามนโยบายความเป็นส่วนตัวของตน

6. คำถามและสิทธิของคุณ

หากต้องการเข้าถึง แก้ไข ลบ หรือระงับการประมวลผลข้อมูลส่วนบุคคล หรือมีคำถาม โปรดติดต่อ ipe.haven@gmail.com แอปไม่เก็บข้อมูลส่วนบุคคล จึงอาจไม่มีข้อมูลให้เราดำเนินการตามคำขอ

7. เด็ก

แอปไม่ได้มุ่งให้เด็กอายุต่ำกว่า 14 ปีหรืออายุต่ำกว่าเกณฑ์ขั้นต่ำในภูมิภาคของคุณใช้งาน และไม่เก็บข้อมูลส่วนบุคคลจากผู้ใช้รายใด
