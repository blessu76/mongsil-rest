Kebijakan Privasi

Berlaku 19 November 2026 · Dikelola oleh Davy Kim (ipe Studio)

Ringkasan Mongsil tidak mengumpulkan data pribadi. Gim ini tidak memiliki server sendiri, akun, iklan, atau alat analitik.

1. Informasi yang dikumpulkan

Mongsil (“Aplikasi”) adalah gim seluler yang dikelola pengembang independen Davy Kim (ipe Studio). Aplikasi tidak membutuhkan akun atau login dan tidak mengumpulkan nama, email, kontak, lokasi, atau data pribadi lainnya. Aplikasi membuat ID acak per perangkat khusus untuk membedakan catatan koin. Jika kamu mengaktifkan iCloud, ID ini dapat disinkronkan bersama progres ke iCloud milikmu tanpa dikirim ke ipe. Catatan perawatan, pengaturan, dan koleksi tersimpan di perangkatmu dan hanya disinkronkan jika iCloud diaktifkan. ipe tidak menerima data ini. Menghapus Aplikasi akan menghapus datanya dari perangkat.

Aplikasi tidak berisi iklan, SDK analitik, atau SDK pelacakan.

2. Penyimpanan perangkat dan iCloud

Pada versi iOS saat ini, progres disimpan di perangkat. Jika iCloud diaktifkan di iPhone, progres disinkronkan lewat iCloud Apple antarperangkat yang menggunakan Akun Apple yang sama. ipe tidak punya server sendiri dan tidak menerima data ini.

Kami akan memperbarui kebijakan ini jika Aplikasi dirilis di platform lain.

3. Situs web

mongsil.ipe.rest tidak memakai alat analitik untuk mengumpulkan statistik kunjungan. Situs dihosting di GitHub Pages. Alamat IP dan catatan akses lainnya dapat disimpan di log server GitHub. Kami tidak mengumpulkan atau menggunakan log itu dan kebijakan GitHub berlaku.

4. Pembayaran

Barang berbayar hanya dijual melalui pembelian dalam aplikasi Apple di App Store. Apple menangani informasi pembayaran seperti nomor kartu dan metode pembayaran. Mongsil dan ipe tidak menerima atau menyimpannya. Pemeriksaan dan pemulihan pembelian menggunakan catatan toko Apple.

5. Pihak ketiga

Aplikasi tidak mengumpulkan data pribadi sehingga tidak ada data yang dibagikan atau dijual ke pihak ketiga. Apple mendistribusikan Aplikasi melalui App Store dan menangani data unduhan dan pembayaran sesuai kebijakan privasinya.

6. Pertanyaan dan hakmu

Untuk meminta akses, koreksi, penghapusan, penghentian pemrosesan data pribadi, atau mengajukan pertanyaan, hubungi ipe.haven@gmail.com. Aplikasi tidak menyimpan data pribadi, sehingga mungkin tidak ada data yang bisa kami temukan untuk diproses.

7. Anak-anak

Aplikasi tidak ditujukan untuk anak di bawah usia 14 tahun atau usia minimum di wilayahmu dan tidak mengumpulkan data pribadi dari pengguna mana pun.

10. Perubahan

Jika penambahan server, akun, iklan, atau analitik mengubah data yang dikumpulkan, kami akan memperbarui kebijakan ini dan tanggal berlakunya terlebih dahulu.
